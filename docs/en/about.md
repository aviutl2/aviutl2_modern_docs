# About This Site

This site is unofficial documentation for [AviUtl2](https://spring-fragrance.mints.ne.jp/aviutl/) created by <a style="color: #48b0d5 !important" href="https://sevenc7c.com" target="_blank">Nanashi.</a>.
It converts and adapts the contents of AviUtl2's `aviutl2.txt` and `lua.txt` for publication.

The source code is available on [GitHub](https://github.com/aviutl2/aviutl2_modern_docs).

A mirror of the AviUtl2 SDK is also available [here](https://github.com/aviutl2/aviutl2_sdk_mirror).

> [!NOTE]
> The document was translated from Japanese to English using GPT-5.5.
> The translation may contain inaccuracies, and the original Japanese version should be considered the primary source.
>
> Translations of UI elements such as menu items are based on [AviUtl2 Community Translation](https://github.com/aviutl2/aviutl2_community_translation).
> It is recommended to install the community translation to match this documentation.

## Main Changes

- Rewritten in Markdown.
  - Keyboard keys are displayed with <kbd>Key</kbd> markup.
  - Lua code and file paths that appear inline are displayed as `inline code`.
- Applied StyLua to Lua code.
- Added search.
- Changelog: newer versions are shown first.
- Changelog: entries are formatted as bullet lists.
- Changelog (Lua): added the corresponding AviUtl2 version.
- Added llms.txt.
- Added notes to several sections.

> Notes are displayed like this.
