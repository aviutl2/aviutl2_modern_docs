# バイナリについて

## Lua/LuaJITのバイナリについて

付属のlua.dllはLuaのサイトにあるバージョン5.1.4に
5.1.4-2のパッチを当ててビルドしたものです。

付属のluaJIT.dllはLuaJITのサイトにあるバージョン2.1をビルドしたものです。

- Luaのサイト
  <http://www.lua.org/>
- LuaJITのサイト
  <https://luajit.org/>
